Design notes

Why this layout looks the way it does. Press N to close.

The two-layer rule

Content is flat: the page is --void, a card is --surface, a well is --inset — elevation is a lightness step, never a shadow. Glass lives only on the floating functional layer: top bar, sidebar, pickers, the Ask capsule, sheet scrims. Never glass on glass.

The glass recipe

rgb(var(--surface-rgb)/.72) + blur(18px) saturate(1.4), with a dual edge: an accent hairline (--panel-line-dim) that carries the edge on dark palettes, and an inset surface sheen that carries it on light ones. Each fades out exactly where the other takes over — that is what makes one recipe work across all seven palettes.

The shadow ruling

The reference rule is “never use a shadow to raise something.” Cards obey absolutely. Glass cannot be raised by lightness — it has none of its own — so the floating layer alone carries one ambient float built from --scrim-rgb, each palette's own idea of darkness: indigo-navy under QUARTZ, near-nothing under VOID. A tinted shadow, never black.

The accent budget

Five spends: the brand Σ · the Ask capsule (the view's one primary action) · the active-nav dot · soon badges · the focus ring. If two accented things are visible at once, one of them is wrong. Active and selected states are ink-filled, not accent-filled — near-black on light palettes, near-white on dark, from the same two tokens.

Type

Sans is what a human wrote; mono is what a machine produced — counts, times, git state, key hints, readouts. Weight 300 only at display sizes (the greeting, KPI numerals); nothing bolder than 500 anywhere. Every numeral is tabular.

Status

Status is never colour alone: every chip carries a word, warnings carry a glyph too. Chips are a 12% tint of their own hue with the full-strength hue as text. Bronze means exactly one thing — “never leaves this machine” — and is spent on nothing else.

What's omitted

The brain. The graph lives in the Instrument layout — the office gets the machine's facts instead: the SYSTEM strip and the footer dock. Everything else has a named home here; nothing was silently dropped. Agents, Career and System keep their soon pills — nothing pretends to exist.

Fallbacks

prefers-reduced-transparency turns glass opaque, prefers-contrast doubles hairlines and chip tints, prefers-reduced-motion stops all transitions, and a browser without backdrop-filter gets solid surfaces. The layout owes nothing to the effects.

One mockup-only substitution: this hosted page uses a heavier tint instead of live blur, because the artifact sandbox cannot composite backdrop-filter. The repo copy (interface/mockups/enterprise-layout.html) and the real implementation blur.
